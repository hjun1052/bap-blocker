# Chrome 웹 스토어 등록 정보

## 기본

- **이름**: 밥 방해요소 차단기
- **카테고리**: 개인정보 보호 및 보안 (Privacy & Security, "Chrome 맞춤설정" 그룹) — 대안: 도구 (Tools)
- **언어**: 한국어

## 간단한 설명 (132자 이내, manifest `description`과 동일)

일부 급식 사이트의 광고 배너를 숨겨 식단만 깔끔하게 보여 줍니다. 비공식 확장 프로그램이며 해당 사이트 운영자와 관련이 없습니다.

## 자세한 설명

일부 급식 사이트에서 식단 사이사이에 들어간 광고 배너를 숨깁니다.

· 카카오 애드핏, 구글 애드센스, 제휴 이미지 배너 등 광고 칸을 감춥니다.
· 광고 요청 자체를 막아 페이지가 가볍습니다.
· 툴바 아이콘을 눌러 언제든 보호를 일시 중지하거나 다시 켤 수 있습니다.
· 지원하는 급식 사이트에서만 동작하며, 다른 사이트에는 아무 영향이 없습니다.
· 어떤 개인정보도 수집하거나 외부로 보내지 않습니다.

※ 이 확장 프로그램은 비공식 도구이며 해당 사이트 및 그 운영자와 관련이 없습니다.

## 단일 용도 (Single purpose)

지원하는 급식 사이트에 표시되는 광고를 숨기고 광고 요청을 차단합니다.

## 권한 사유

- **declarativeNetRequest**: 지원하는 급식 사이트 페이지가 보내는 광고 스크립트·광고 이미지·광고 집계 요청을 차단하기 위해 사용합니다. 차단 규칙은 확장 프로그램에 포함된 고정 목록(rules.json)이며, 해당 사이트에서 시작된 요청에만 적용됩니다.
- **storage**: 보호 켜기/끄기 상태와 누적 차단 수를 기기에 저장하기 위해 사용합니다.
- **호스트 권한**: 지원하는 급식 사이트(manifest의 호스트 권한에 적힌 도메인 하나) 페이지에 스타일과 스크립트를 넣어 광고 칸을 숨기고, 팝업에 현재 페이지의 차단 수를 표시하기 위해 필요합니다. 다른 사이트에는 접근하지 않습니다.
- **원격 코드 사용**: 아니요. 모든 코드는 패키지에 포함되어 있습니다.

## 개인정보 보호 관행 (Privacy practices 탭)

- 수집하는 사용자 데이터: **없음** (모든 항목 체크 해제)
- 인증 항목 세 개 모두 체크:
  - 승인된 사용 사례 외의 목적으로 사용자 데이터를 판매하거나 전송하지 않음
  - 단일 용도와 무관한 목적으로 사용자 데이터를 사용하거나 전송하지 않음
  - 신용도 판단 또는 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 개인정보처리방침 URL: 데이터를 다루지 않으므로 필수 아님. 요구되면 아래 문구를 GitHub 등에 올려 링크.

> 밥 방해요소 차단기는 어떤 개인정보도 수집·저장·전송하지 않습니다. 보호 켜기/끄기 설정과 차단 수는 사용자의 브라우저 안(chrome.storage.local)에만 저장되며 외부로 전송되지 않습니다.

> 스토어에 공개되는 문구(이름·설명·스크린샷)에는 사이트 이름을 쓰지 않음. 도메인은 manifest 권한에만 있음.
